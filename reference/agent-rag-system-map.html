AI ChatKit：黑盒系统速查表

浏览器 → 前端 → HTTP API → Agent Graph → LLM
　　　　　　　　　　　　　　　↘ Tool → SQLite / Chroma → Ollama embedding
组件负责什么不是做什么
DeepSeek理解问题、生成回答、决定是否调用工具不保存 PDF，也不直接查询 SQLite
LangGraph规定模型与工具按什么顺序运行不是模型本身
Tool让 Agent 调用受控 Python 能力不是任意执行用户输入
Ollama + bge-m3将文本变成可比较的向量不负责最终自然语言回答
Chroma存储向量并返回相似文本块不判断最终答案是否正确
SQLite保存结构化员工、部门数据不适合语义相似度检索
FastAPI接收浏览器请求、返回 JSON/SSE不等于 Agent workflow
Next.js展示聊天界面、发送请求、显示流式结果不执行 Python Tool

记忆句：LLM 决定，Graph 编排，Tool 动手，Embedding 表示，Chroma 找资料，FastAPI 传递，前端展示。
